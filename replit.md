# Guess Number Game

A Python number guessing game with a tkinter desktop GUI.

## About

`eric.py` — a tkinter-based GUI game where the player guesses a random number. Features:
- **Casual mode**: set your own Min/Max range
- **Competitive mode**: preset difficulty levels (1–100, 1–1000, 1–10000)
- Best score tracking saved to local `.txt` files per difficulty level

## Running locally

This app uses tkinter and requires a graphical display. It is not compatible with Replit's browser preview out of the box.

To run locally:
```bash
python eric.py
```

## Stack

- Python 3.12
- tkinter (standard library)
